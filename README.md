# Arabee – Bahan Ajar Bahasa Arab Inklusif (Materi 1: At-Ta‘āruf)

Website statis (HTML, CSS, JS). Tanpa build step.

## Jalankan lokal
Buka `index.html`, atau jalankan `npx serve .`

## Deploy ke Vercel
1. Push folder ini ke GitHub.
2. Di vercel.com pilih **Add New → Project**, import repo.
3. Framework Preset: **Other**. Build Command dan Output Directory dibiarkan kosong. Klik **Deploy**.

Catatan: suara memakai Web Speech API (Chrome/Edge paling stabil). Mikrofon butuh HTTPS, yang sudah disediakan Vercel.
